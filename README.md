# Sistem Kasir Sederhana

Program kasir berbasis CLI (Command Line Interface) menggunakan Python.
Dibuat untuk Tugas Individu "Implementasi Coding Standard & Version Control".

## Cara Menjalankan

```bash
python main.py
```

## Fitur
- Menampilkan daftar produk
- Menambah / menghapus produk di keranjang
- Diskon otomatis berdasarkan total belanja
- Cetak struk pembayaran
